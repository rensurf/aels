以下のコマンドでテストスイートを実行してください。

```bash
pytest tests/ --cov=src --cov-report=term-missing -v
```

## 実行後の確認事項

1. **失敗したテスト** があれば、エラーメッセージを読んで原因を特定し、修正案を提示してください
2. **カバレッジが 80% 未満** のファイルがあれば、どのコードパスが未テストか確認して追加すべきテストケースを提案してください
3. **全テスト通過・カバレッジ 80% 以上** であれば「テスト OK」と報告してください

## 前提

- `pyproject.toml` に `asyncio_mode = "auto"` が設定されていること
- `.env` が存在しない場合は環境変数のモックを使用すること
- 統合テスト (`tests/integration/`) は `-m "not integration"` で除外して実行してもよい
